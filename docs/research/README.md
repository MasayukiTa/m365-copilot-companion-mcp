# docs/research — 実装計画の保管場所

このフォルダは、着手前の実装計画を「決めた順序のまま」書き留めておくための場所です。
会話やチャット履歴は流れて消えますが、ここに置いた計画は残り、計画順での着手を忘れずに追えます。

## 使い方

- 1 つの取り組み（テーマ）につき 1 ファイル。`YYYY-MM-DD-<topic>.md` の名前にします。
- 各ファイルの先頭に、着手する順番（番号付き）とその理由を書きます。
- 着手・完了したら、該当ステップの行頭に状態（[ ] 未 / [x] 済）を付けて更新します。

## 収録ファイル

- `2026-09-08-implementation-order.md` — 初期の実装順計画（looped 等）。

## 背景

この保管場所は、依頼「この順で。忘れないよう docs/research に置いておいて」に対応します。
計画をコードベース内に残すことで、後続の走行・担当者が同じ順序を参照できます。
