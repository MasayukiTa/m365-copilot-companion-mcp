POPULATION
  turns replayed           120
  ... whose text EVER changed  98
      A turn whose text never moved cannot exhibit truncation, so it carries no
      information about the primary endpoint. The informative N is the second
      number, not the first.
  independent clusters     12
      Turns sharing a prompt are not independent observations of the rule; they
      are repeats of one observation. 120 turns over 12 prompts is 12 clusters, and
      any interval computed as though N were 120 is too narrow.

PRIMARY -- truncated capture (accepted text != the text the turn settled to)
  legacy rule              0 / 120
  unified rule             0 / 120
  label observation window median 7.7s (min 7.5, max 8.2)
      THE LABEL IS BLIND PAST THAT WINDOW. The failure being counted is a long
      streaming pause, so a pause longer than the tail is recorded as 'the text
      never grew' -- indistinguishable from no pause at all. A zero here is not
      evidence that truncation does not happen; it is evidence that none was
      visible within 8 seconds of the accept.

  truncations visible INSIDE the recorded window, needing no tail at all:
     legacy 0   unified 0
  stillness before the legacy accept: median 4.3s
  SO THE CORPUS SEES PAUSES UP TO ABOUT 12 SECONDS (that stillness plus the
  tail) AND FINDS NONE. What it cannot speak to is a stream that goes quiet
  for longer than that and then resumes. The claim is bounded, not absent.

SECONDARY -- where the two rules disagree
  turns with different accept points  4 / 120
  legacy never accepted    0
  unified never accepted   0
      A turn the unified rule never accepts inside the recorded window is the
      REGRESSION the plan names: production settled it and the stricter rule would
      still be waiting. Recorded windows are finite, so this over-counts -- it is a
      list to investigate, not a verdict.

SIDE EFFECT -- added latency (the plan budgets +1.5s on the median)
  median  +0.00s   p95  +0.00s   (n=120 paired turns)
  within the +1.5s budget: yes

VERDICT
  BOUNDED, NOT ABSENT. Within this corpus neither rule truncated a turn whose
  stream went quiet for up to about 12 seconds. Above that the corpus is silent,
  and silence is not a zero. So the primary endpoint is answered for short pauses
  and open for long ones -- which is the interesting half, since the failure this
  replaces was described as a pause that outlasted the dwell.

  STAGE 1 IS STILL NOT JUSTIFIED, for a reason that is not about the tail: 12
  clusters cannot support the discordant-pair count the plan's own power
  calculation asks for (~40 pairs, N about 450-700 TURNS across many prompts).
  What would move this on is a wider collection -- more prompts, not more repeats
  of these -- with the longer post-accept tail now in place.
