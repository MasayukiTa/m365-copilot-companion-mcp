# 夜間調査バッチ 使い方(1ページ)

寝る前に調べたいことを書いておくと朝にまとまったレポートができあがります。

## 1. 調査項目ファイルを作る(items.txt)

1行に1項目、短い日本語で書きます。先頭に `ID: ` を付けてもかまいません。

```
# 前置き: 数値は小数1桁で
過去1か月の不良データを集計して
A2: 品種ごとの月別推移を出して
```

`#` で始まる行と空行は無視されます(`# 前置き:` だけは全項目に共通の1文になります)。
同じ依頼や同じIDは自動で除かれ、レポートに「未実施」として載ります。上限は50項目です。

## 2. 夜に1コマンド

```
python -m tools.overnight run --items items.txt --start-at 02:00 --deadline 07:00
```

- `--start-at` : その時刻まで待ってから始めます(待っている間、PCはスリープしません)。
- `--deadline` : その時刻を過ぎたら新しい依頼を出さず、そこまでの結果でレポートを作ります。
- `--max-minutes-per-item` : 1項目の時間予算(分)。超えると「時間切れ」と記録します(作業は止めません)。
- `--submit-route queue`(既定、夜間向け): フリートの待ち行列に直接入れます。画面ロック中でも動きます。
  `--submit-route gui`(昼間向け): コックピットの画面操作で入れます。画面ロック中は投入できません。
- 投入できなかった項目があるとレポートの先頭に「N 件中 M 件が投入できませんでした」と出ます。
- レポートの最後に「整合検査」(レポートとフリートの作業者一覧の突き合わせ)が必ず付きます。
- PCの電源・画面設定は変更しません。

## 3. 朝に見るもの

出力フォルダ(既定: ドキュメント\朝レポート\日付_時刻)に次ができます。

- `朝レポート_日付.xlsx` : サマリ / 失敗と未完 / 実行情報 / 項目ごとのシート
- `朝レポート_日付.md`、`.html` : 同じ内容の読みやすい版
- `READY.txt` : 完成の目印(できあがるとトースト通知も出ます)

サマリの `OK/NG` 列に ○ か × を付けておくと次回の実行時(または
`python -m tools.overnight feedback --report <xlsx>`)に記録され、今後の改善に使えます。

## 4. うまくいかなかったとき

「失敗と未完」シートに原因(DB接続不可 / ロック / タイムアウト / 依頼が曖昧 / その他)と、
翌朝にやることが書いてあります。途中で止まった場合は

```
python -m tools.overnight resume --out <出力フォルダ> --retry-failed
```

で続きを実行できます。同じ依頼を二重に出すことはありません。
