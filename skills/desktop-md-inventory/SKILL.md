# desktop-md-inventory

デスクトップ直下（サブフォルダは含めない）の `.md` ファイルを数え、一覧にする定型作業の手順書。

## 使うツールと引数

- `list_directory` を1回呼ぶ。
  - `path`: `Desktop`（利用者のホーム配下として解決される。絶対パスを書き下さない）。
  - `pattern`: `"*.md"`。
- `pattern` を指定するとディレクトリは除外され、直下のファイルのうち一致するものだけが対象になる。`recursive` は指定しない（既定 false のまま）ので、サブフォルダには入らない。

## 数え方

- `list_directory` の出力の **1行目** に件数が出る（例: `16 files matching *.md in ...`）。この数字をそのまま件数とする。
- 一覧を目視で数え直さない。1行目の件数を答えとして使う。

## 出力の形

- 件数を先に示す（例: 「デスクトップ直下の .md は 16 件」）。
- 続けてファイル名の一覧を出す。`list_directory` は各行に `[FILE] ファイル名 (バイト数)` の形で返すので、その一覧をそのまま提示する。
