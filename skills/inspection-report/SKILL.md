# 設備点検記録 月次サマリ作成 Skill

## 目的
設備点検記録のExcelを読み込み、各測定項目の統計と規格外れ行を集計し、月次サマリ（JSON / Markdown / グラフPNG）を生成する。

## 入力
- Excelファイル1つ。列は以下を前提とする。
  - 時刻
  - 温度(℃)
  - 圧力(kPa)
  - 流量(L/min)
  - 判定

## 実行方法（厳守）
- 集計は **毎回 scripts/summarize.py を使う**。自分で集計コードを書き直さない。
- 実行コマンド:
  ```
  python scripts/summarize.py <Excelファイルのパス>
  ```
- summarize.py は引数にExcelパスを1つ取る。
- 同じ入力からは必ず同じ出力になる（再現性が最重要）。判定基準・丸め・並び順はすべてコード内に固定されている。集計ロジックを外部で変更・再実装してはならない。

## 判定基準（規格）
summarize.py 内に定数として保持している。参照用に以下に記す（正はコード）。
- 温度(℃): 70.0 〜 76.0
- 圧力(kPa): 100.0 〜 102.5
- 流量(L/min): 44.0 〜 46.0

各行について、3項目のうち **1つでも範囲外なら、その行を「規格外れ」** とする。境界値（下限・上限そのもの）は範囲内とする。

## 出力
summarize.py は以下を生成する。
1. **標準出力にJSON**: 各項目の件数・平均・最小・最大、規格外れ行数、規格外れ行の詳細を含む。
2. **点検サマリ.md**: Excelと同じフォルダに出力。統計表と規格外れ行の一覧を含む。
3. **点検サマリ.png**: Excelと同じフォルダに出力。温度・圧力・流量の時系列グラフに規格範囲を重ねたもの。

## 出力書式（JSON）
```
{
  "file": "入力Excelの絶対パス",
  "row_count": 行数,
  "metrics": {
    "温度(℃)":   {"min":..,"max":..,"mean":..,"spec_min":70.0,"spec_max":76.0,"out_of_spec":件数},
    "圧力(kPa)": {"min":..,"max":..,"mean":..,"spec_min":100.0,"spec_max":102.5,"out_of_spec":件数},
    "流量(L/min)":{"min":..,"max":..,"mean":..,"spec_min":44.0,"spec_max":46.0,"out_of_spec":件数}
  },
  "out_of_spec_rows": [ {"時刻":..,"温度(℃)":..,"圧力(kPa)":..,"流量(L/min)":..,"理由":[..]} ],
  "out_of_spec_count": 規格外れ行数
}
```

## 手順（担当者向け）
1. 入力Excelのパスを確認する。
2. `python scripts/summarize.py <Excelパス>` を実行する。
3. 標準出力のJSONを確認し、out_of_spec_count と out_of_spec_rows を点検結果として報告する。
4. 生成された 点検サマリ.md と 点検サマリ.png を成果物として添付する。
5. 数値はコード出力をそのまま用いる。手計算で上書きしない。
