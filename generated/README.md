# generated/

Files in this directory are produced by `scripts/bootstrap.py` (run via
`setup.bat`). They are environment-specific helpers, not source.

- `copilot-connector.md` -- step-by-step checklist for adding this MCP server to
  a Copilot Studio agent. Written by the `gen_connector` step with a placeholder
  Bearer value. Run `copilot_studio_values.bat` when you need the live value from
  `.env`.

The committed `copilot-connector.template.md` is the same checklist, kept for
reference.
